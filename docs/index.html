Clair sur la sécurité

Tu gardes la main sur tes données.

L’application s’appuie sur les identifiants gérés par GitHub CLI. Elle n’enregistre pas ton jeton dans le cache local et ne télécharge pas d’installateur caché.

  • ✓Le cache contient les données affichées, pas le jeton GitHub.
  • ✓Les versions sont construites depuis le dépôt avec GitHub Actions.
  • ✓Chaque publication fournit une somme SHA-256 vérifiable.
  • ✓Les actions destructives demandent une confirmation explicite.
Les exécutables ne sont pas encore signés. Un avertissement SmartScreen ou antivirus reste possible : vérifie le code et la somme de contrôle, et ne désactive pas ta protection.
Choisis ton environnement

Une application de bureau sur les trois systèmes.

Les paquets sont construits séparément sur chaque plateforme. Ils ne nécessitent pas Python installé.

Windows 10 & 11

Archive avec application sans console. WebView2 et GitHub CLI requis ; Git est nécessaire pour archiver des dépôts.

macOS

Application `.app` dans une archive. GitHub CLI requis. Vérifie l’architecture précisée sur la version téléchargée.

Linux

Archive x64. GTK 3, WebKit2GTK 4.1 et GitHub CLI requis sur le système.
